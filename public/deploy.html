3. Connect Cloudflare (Workers or Pages)

once, then every push redeploys
  1. Workers & Pages → Create → Workers → Import a repository (recommended). Pick the repo and branch, then set: Root directory (empty) · Build command (empty) · Deploy command npx wrangler deploy. Live on https://<name>.<you>.workers.dev.
  2. Or Pages → Connect to Git if you prefer Pages: Framework preset None · Build command (empty) · Build output directory public · Root directory (empty). Live on https://<project>.pages.dev.
  3. Nothing else to configure. wrangler.toml already points at worker.js and serves public/ as static assets, and functions/api/*.js makes the same routes work on Pages.
  4. After publishing delete public/deploy.html from the repo if you do not want other people to see this page.
# local preview (Workers)
npx wrangler dev

# local preview (Pages)
npx wrangler pages dev public --port 8788

# deploy without GitHub
npx wrangler deploy
